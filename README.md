# FNAF Final Night — Android starter

A Kotlin + Jetpack Compose horror-survival prototype.

## Requirements
- Android Studio with Android SDK 35 installed
- JDK 17
- Gradle 8.11.1 or a compatible Gradle installation

## Open and run
1. Extract the project.
2. Open the `FNAFFinalNight` folder in Android Studio.
3. Allow Gradle sync to finish.
4. Run the `app` configuration on an emulator or Android device.

## Prototype gameplay
- A 60-second night represents 12 AM through 6 AM.
- Closing the security door reduces threat but drains more power.
- Using the camera slows threat growth but also consumes power.
- Survive until 6 AM to complete the night.
- Your best survival time is saved locally using Preferences DataStore.

## Notes
- This is a starter prototype, not a finished commercial game.
- The visual camera feed is placeholder UI; it does not yet contain animated enemy movement or rendered camera scenes.
- Replace the placeholder title/branding and add original art, sound, accessibility options, and additional gameplay content before release.
